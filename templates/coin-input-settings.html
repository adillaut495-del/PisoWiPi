Coin input

Tune GPIO17 edge filtering and map measured pulses to coin values.

LOADING

GPIO17 is BCM pin 17 (physical pin 11). The input is isolated by the relay contacts; never apply 5V or 12V to a Pi GPIO. Measure pulse counts before changing the map.

Example: {"1":1,"2":5,"3":10,"4":20} means 1 pulse = P1, 2 pulses = P5, 3 = P10, 4 = P20. Use your probe's measured counts.
